Installation

Sur Windows

  1. Ouvrez le fichier BliGO-Agent-Windows.exe téléchargé.
  2. Si Windows affiche « Windows a protégé votre ordinateur », cliquez sur Informations complémentaires, puis sur Exécuter quand même. Ce message est normal pour un nouveau logiciel.
  3. Suivez l'installation, puis ouvrez BliGO Agent depuis le menu Démarrer.

Sur Mac

  1. Ouvrez le fichier BliGO-Agent-Mac.dmg téléchargé, puis faites glisser BliGO Agent dans le dossier Applications.
  2. Ouvrez BliGO Agent depuis le dossier Applications.
  3. Si le Mac refuse de l'ouvrir, allez dans Réglages Système › Confidentialité et sécurité, descendez jusqu'au message sur BliGO Agent et cliquez sur Ouvrir quand même. Ce n'est à faire qu'une fois.

Première connexion au logiciel

Au lancement, choisissez votre médiathèque, puis connectez-vous avec le compte BliGO que nous vous avons ouvert. Le logiciel se met à jour tout seul : inutile de le réinstaller. Une question ? megane@bligo.fr
